    What is your blog about?

    Connect your WordPress site

    1. Open yourblog.com/wp-admin → Users → Profile.
    2. At the bottom, under Application Passwords, type BlogDraft Studio → Add New Application Password.
    3. Copy the password and paste it below. More help

    Add your Gemini API key

    1. Open aistudio.google.com/apikey and sign in with Google.
    2. Click Create API key and copy it.
    3. Paste it below and click Check key. Writing works on the free plan.

    Pictures for your posts

    Get a free key at pexels.com/api → Your API Key.

              Search Console

              See which posts Google shows, which almost reach page 1, and what people search that you haven't written yet.

              How to get the file (1 minute)

              1. Open search.google.com/search-console and choose your site.
              2. Click Performance (Search results). Set the date to Last 3 months.
              3. Top right: Export → Download CSV. A zip file is saved.
              4. Click Open Search Console export above and choose that zip. Nothing is uploaded anywhere; it stays on this computer.
